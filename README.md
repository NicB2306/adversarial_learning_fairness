# adversarial_learning_fairness
Evaluating the bias mitigation technique of adversarial learning and applying it to datasets Adult, German and COMPAS.

Based on the research paper https://arxiv.org/pdf/1801.07593 and on its implementation within the AIF360 GitHub repository: https://github.com/Trusted-AI/AIF360.git

Reproduction of this implementation can be done through the notebook attached.
